================================================================================
IMPLEMENTATION OVERVIEW
================================================================================

CORE COMPONENTS:

GeminiClient
  - Lightweight HTTP client using urllib
  - No external dependencies beyond stdlib
  - Methods: generate(), generate_json()
  - Environment: GEMINI_API_KEY

BaseAgent
  - Abstract base class for agents
  - Shared LLM client access
  - Standard run() interface
  - Topic extraction helpers

KnowledgeGraphAgent ⭐ MAIN AGENT
  - Builds semantic knowledge graphs
  - Input: Query string + optional explorer_output
  - Output: Nodes, edges, insights, metrics
  - Two-level fallback system
  - Never fails - always returns valid graph
