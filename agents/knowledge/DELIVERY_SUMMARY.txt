AGENT COMPONENTS:

1. GeminiClient
   - Lightweight API client using urllib
   - No external dependencies beyond stdlib
   - Environment: GEMINI_API_KEY
   - Methods: generate(), generate_json()
   - Fallback: Graceful when API unavailable

2. BaseAgent
   - Abstract base for all agents
   - Shared LLM client (_gemini)
   - Topic extraction (_extract_topic)
   - Standard interface: run(context) -> dict

3. KnowledgeGraphAgent
   - Main agent implementation
   - Input: Query string (and optional explorer_output)
   - Output: Knowledge graph (nodes, edges, insights, metrics)
   - Fallback strategies:
     * Simple: 5-7 nodes from keywords
     * Structured: 10-20 nodes from explorer data

FEATURES IMPLEMENTED:

✓ Gemini API Integration
  - Gemini 2.0 Flash model
  - Temperature optimization (0.4 for JSON)
  - 30-second timeout
